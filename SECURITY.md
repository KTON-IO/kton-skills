# Security

Report a vulnerability privately to contact@kton.io, not in a public issue. Say what can happen and how to reproduce it; we will answer and agree on when it can be made public.

In scope: the script (`src/`, built into `kton/scripts/kton.mjs`), the instructions in `kton/SKILL.md` and its references, and anything that could make an agent send a transaction the user did not agree to.
